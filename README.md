# Avila Musselers

Port San Luis tides, mussel season and daily biotoxin status, as a home-screen web app.

- Tides are computed in the page from NOAA's harmonic constants for station 9412110 (Port San Luis).
- `status.json` holds the latest CDPH biotoxin check for San Luis Obispo County and is updated each morning.
- Background photo © the site owner. Tide data: NOAA CO-OPS.
